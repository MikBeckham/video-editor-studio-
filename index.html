Everything You Need to Edit

A complete feature set rivaling desktop editors — all in your browser.

🎬
Multi-Track Timeline
Video, audio, text, and sticker tracks with drag-drop, trim, split, snap, zoom, and bulk operations.
✨
Rich Animations
13 entrance + 4 exit + 7 continuous loop animations, plus keyframe-based motion with 4 easing curves.
🔀
18 Transitions
Fade, dissolve, slide, zoom, wipe, circle, diamond, glitch, flash, blur — with adjustable duration.
🎨
14 Filter Presets
Vivid, Warm, Cool, Vintage, B&W, Sepia, Noir, Dramatic, Fade, Dreamy, Vignette, Invert, Blur + 9 manual adjustments.
✍️
Text & Captions
10 templates × 10 style presets × 12 fonts. Stroke, shadow, background, letter-spacing — full control.
💾
Multi-Format Export
MP4 (H.264), WebM (VP9), Animated GIF. MediaRecorder (fast) or FFmpeg.wasm (true H.264).
⌨
Pro Keyboard Shortcuts
Undo/redo, copy/paste, multi-select, ripple delete, nudge clips, split, snap — all standard editor shortcuts.
🔊
Audio Waveforms
Real-time canvas-rendered waveforms on audio clips. Tone generator (beep/chime/drum/music) via Web Audio API.
🚫
No Server Required
100% client-side. No API keys, no backend, no paid dependencies. Just a static deploy.

Get Started in 3 Steps

No build pipeline configuration needed. Just install and run.

1. Clone & Install

# Clone the repository git clone https://github.com/YOUR_USERNAME/video-editor-studio.git cd video-editor-studio # Install dependencies (Bun recommended) bun install # OR with npm/yarn/pnpm npm install

2. Run Dev Server

# Start development server bun run dev # Server starts at http://localhost:3000 # Open in your browser # Build for production bun run build bun run start

3. Quick Tips

# Click the "Demo" button in the header to load a sample project # Press Space to play, ? to see all shortcuts, H for the user guide # Drag any asset from the left sidebar directly to the timeline # Press Ctrl+E to export your video as MP4, WebM, or GIF # Save your project as JSON for later: Ctrl+S # Reopen with Ctrl+O — your timeline is restored exactly
